# Snack-Analysis-Starbucks-vs.-McDonald-s---PySpark

## Project Overview
This project analyzes and compares the nutritional information of Starbucks and McDonald's menu items using PySpark.

## Files Included

### Main Submission Files
- `Snack_Analysis.ipynb` — PySpark notebook containing the data loading, cleaning, transformation, analysis, and comparisons.
- `PRCE-002_Analysis_Report.docx` — Analysis report presenting the findings and conclusions.
- `PRCE-002_Challenges_Report.docx` — Report describing the challenges faced during the project and their resolutions.

### Optional Supporting Files
- `overall_comparison.csv` — Overall nutritional comparison between Starbucks and McDonald's.
- `brand_item_type_comparison.csv` — Nutritional comparison by brand and item type.
- `missing_values.csv` — Missing-value summary by brand.
- `extreme_items.csv` — Selected extreme nutritional items identified during analysis.
- `supporting_analysis.sql` — SQL examples corresponding to the main analysis queries.

## Technologies Used
- Python
- PySpark
- Pandas
- Excel datasets
- SQL
